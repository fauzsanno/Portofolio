# Joe Digital Lab

Modern portfolio starter built with Next.js, TypeScript, Tailwind CSS and Lucide icons.

## Run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000

## Customize

Edit `app/page.tsx` for your name, bio, projects, skills, GitHub, email and CV link.

## GitHub

`git init`
`git add .`
`git commit -m "Initial portfolio"`
`git branch -M main`
`git remote add origin YOUR_GITHUB_REPOSITORY_URL`
